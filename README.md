# NativeFrame

Lightweight, framework-agnostic UI library built with pure HTML, CSS, and vanilla JavaScript.

## Quick Start

Add NativeFrame to your project via CDN:

```html
<link rel="stylesheet" href="https://unpkg.com/nativeframe/dist/nativeframe.min.css">
<script src="https://unpkg.com/nativeframe/dist/nativeframe.min.js"></script>
```

Or install via npm:

```bash
npm install nativeframe
```

## Features

- Zero dependencies
- CSS-first, JS-optional
- Accessible by default (ARIA + keyboard support)
- 15 ready-to-use components
- Dark mode support

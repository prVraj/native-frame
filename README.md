# NativeFrame

A lightweight, framework-agnostic UI component library built with pure HTML, CSS, and vanilla JavaScript. No dependencies. No build step required. Just drop it in and go.

## Features

- **Zero dependencies** — No runtime packages, no framework lock-in
- **CSS-first** — Most components work with CSS alone; JavaScript is optional
- **Accessible** — ARIA patterns, keyboard navigation, and focus management built in
- **15 components** — Buttons, inputs, modals, toasts, tabs, accordions, and more
- **Dark mode** — Automatic via `prefers-color-scheme`, or toggle manually with a class
- **Tiny footprint** — Under 10 KB total (minified + gzipped)

## Quick start

### Option 1: Build from source

```bash
git clone https://github.com/prVraj/native-frame.git
cd native-frame
npm install
npm run build
```

Then link the built files in your HTML:

```html
<link rel="stylesheet" href="dist/nativeframe.min.css">
<script src="dist/nativeframe.min.js" defer></script>
```

### Option 2: Copy the dist files

After building, copy `dist/nativeframe.min.css` and `dist/nativeframe.min.js` into your project and reference them directly.

## Usage

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My App</title>
  <link rel="stylesheet" href="dist/nativeframe.min.css">
</head>
<body>

  <div class="nf-container" style="padding: 2rem;">
    <button class="nf-btn nf-btn-primary" id="hello">Click me</button>
  </div>

  <script src="dist/nativeframe.min.js" defer></script>
  <script>
    document.getElementById('hello').addEventListener('click', function () {
      NF.toast.show('It works!', { type: 'success' });
    });
  </script>

</body>
</html>
```

## Components

| Component | Type | Description |
|-----------|------|-------------|
| Button | CSS | 5 variants, 3 sizes, loading state |
| Input | CSS | Text fields, textareas, groups with prefix/suffix |
| Select | CSS | Styled native dropdown |
| Checkbox & Radio | CSS | Custom styled form controls |
| Toggle | CSS | On/off switch |
| Card | CSS | Content container with header, body, footer |
| Badge | CSS | Status labels and counters |
| Avatar | CSS | User images or initials |
| Skeleton | CSS | Shimmer loading placeholders |
| Layout | CSS | Grid, flex, stack, cluster, container |
| Modal | CSS + JS | Dialog with focus trap and keyboard support |
| Toast | CSS + JS | Stacking notifications with auto-dismiss |
| Tabs | CSS + JS | Tabbed content with arrow key navigation |
| Accordion | CSS + JS | Collapsible panels with single-open mode |
| Tooltip | CSS + JS | Hover/focus hints with auto-positioning |

## JavaScript API

All interactive components are available under the global `NF` object:

```javascript
NF.modal.open('#my-modal');
NF.modal.close('#my-modal');

NF.toast.show('Saved!', { type: 'success' });
NF.toast.dismiss(toastElement);
NF.toast.dismissAll();

NF.accordion.toggle(triggerElement);
NF.tabs.select(tabElement);
NF.tooltip.show(element);
```

Most components also work without JavaScript using `data-` attributes:

```html
<button data-modal-open="my-modal">Open Modal</button>
<button data-tooltip="Helpful hint" data-tooltip-pos="top">Hover me</button>
```

## Development

```bash
npm install          # Install dev dependencies
npm run build        # Build CSS + JS into dist/
npm run serve        # Start local dev server at http://127.0.0.1:4173
npm run lint:css     # Lint CSS with stylelint
npm test             # Run interaction tests (requires Playwright)
npm run audit        # Run accessibility audit (requires Playwright)
```

## Theming

Override CSS custom properties to change the look globally:

```css
:root {
  --nf-color-primary: #ec4899;
  --nf-color-primary-hover: #db2777;
  --nf-font-family: 'Inter', system-ui, sans-serif;
  --nf-radius-md: 4px;
}
```

Add the `.nf-dark` class to `<html>` for manual dark mode, or let it follow the OS preference automatically.

See the [theming guide](docs/theming.md) for the full list of tokens.

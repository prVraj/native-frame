NativeFrame is a lightweight, dependency-free CSS component library that gives you production-ready UI primitives. No build step. No JavaScript overhead. Just clean, semantic HTML.

Get Started Explore Features

Everything you need, nothing you don't

Thoughtfully designed components that work together out of the box.

T

Design Tokens

A complete token system for colors, spacing, typography, and shadows. Customize the entire theme by editing a handful of CSS custom properties.

L

Flexible Layouts

Grid, flex, stack, and cluster primitives handle any layout pattern. Responsive breakpoint classes adapt seamlessly from mobile to desktop.

A

Accessible by Default

Every interactive component ships with proper focus indicators, ARIA patterns, and keyboard support. Accessibility is baked in, not bolted on.

D

Dark Mode Ready

Automatic dark mode via media query or manual toggle with a single CSS class. All components adapt without extra effort on your part.

Z

Zero Dependencies

No React, no Vue, no build pipeline required. Drop in one CSS file and one optional JS file. Works with any stack or no stack at all.

S

Tiny Footprint

The entire library weighs under 10 KB gzipped. No bloated utility classes or unused selectors. Ship exactly what your users need.

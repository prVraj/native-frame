Components

Button

Buttons trigger actions and navigate between pages. NativeFrame buttons come in multiple variants and sizes.

Primary Button

The main call-to-action button. Solid brand color background with white text.

<button class="nf-btn nf-btn-primary nf-btn-sm">Small</button> <button class="nf-btn nf-btn-primary">Medium</button> <button class="nf-btn nf-btn-primary nf-btn-lg">Large</button> <button class="nf-btn nf-btn-primary nf-btn-xl">Extra Large</button>

Secondary Button

White background with a gray border. Used for secondary actions alongside a primary button.

<button class="nf-btn nf-btn-secondary nf-btn-sm">Small</button> <button class="nf-btn nf-btn-secondary">Medium</button> <button class="nf-btn nf-btn-secondary nf-btn-lg">Large</button>

Outline Button

Transparent background with a brand-colored border. Fills with a subtle brand tint on hover.

<button class="nf-btn nf-btn-outline nf-btn-sm">Small</button> <button class="nf-btn nf-btn-outline">Medium</button> <button class="nf-btn nf-btn-outline nf-btn-lg">Large</button>

Ghost Button

No background, no border. Appears as plain text, reveals a subtle fill on hover.

<button class="nf-btn nf-btn-ghost nf-btn-sm">Small</button> <button class="nf-btn nf-btn-ghost">Medium</button> <button class="nf-btn nf-btn-ghost nf-btn-lg">Large</button>

Link Button

Styled as a text link but functions as a button. No padding, no border.

<button class="nf-btn nf-btn-link">Learn more</button>

Danger Button

Destructive action buttons. Solid red for primary destructive, outlined for secondary.

<button class="nf-btn nf-btn-danger">Delete account</button> <button class="nf-btn nf-btn-danger-secondary">Remove item</button>

Icon, Disabled & Loading

Icon-only buttons, disabled state, and loading spinner state.

<!-- Icon only --> <button class="nf-btn nf-btn-primary nf-btn-icon" aria-label="Star">★</button> <!-- Disabled --> <button class="nf-btn nf-btn-primary" disabled>Disabled</button> <!-- Loading --> <button class="nf-btn nf-btn-primary nf-btn-loading">Loading</button>

Full Width Button

Stretches to fill its container width. Useful inside forms and cards.

<button class="nf-btn nf-btn-primary nf-btn-full">Sign up</button>

Toast

Sonner-style stacked notifications with a built-in progress timer. Only 4 toasts are visible at once — older ones scale down and peek behind the newest, creating a smooth perspective stack.

Individual Toasts

Click any button to fire a single toast. Watch the progress bar count down the remaining time at the bottom.

NF.toast.show('Your message here', { type: 'success', // 'success' | 'error' | 'warning' | 'info' duration: 4000, // auto-dismiss in ms (0 = persistent) dismissible: true, // show close button position: 'bottom-right' });

Perspective Stack (4 visible)

Click quickly to stack multiple toasts. Only the 4 newest are visible — older ones animate backward with decreasing scale and peek from behind the front toast.

// Fire multiple toasts rapidly. // Only 4 newest are visible at once. // Older toasts scale down (0.95, 0.90, 0.85) and peek // from behind the front toast via negative translateY. const msgs = [ { msg: 'Downloading your patience...', type: 'info' }, { msg: 'Compiling excuses...', type: 'warning' }, { msg: 'Deploying to production on Friday', type: 'error' }, { msg: 'git push --force (no regrets)', type: 'success' }, { msg: 'Reticulating splines...', type: 'info' }, { msg: 'Mass update complete', type: 'success' }, ]; msgs.forEach((m, i) => { setTimeout(() => NF.toast.show(m.msg, { type: m.type, duration: 5000 }), i * 350); });

Notification Flood (20+)

Stress-test with 20 rapid-fire toasts. The stack stays clean — only 4 show, older ones are dismissed as newer ones arrive. Each has its own progress bar ticking down.

// Handles 20+ toasts gracefully. // Only 4 most recent are visible in the stack. // Oldest overflow toasts are auto-removed. // Progress bars tick independently per toast. for (let i = 1; i <= 20; i++) { setTimeout(() => { NF.toast.show('Notification #' + i, { type: ['success','error','warning','info'][i % 4], duration: 6000 }); }, i * 250); }
